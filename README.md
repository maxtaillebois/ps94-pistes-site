# Site de la Fédération PS du Val-de-Marne, trois pistes

Maquettes navigables du futur site vitrine de la Fédération socialiste du Val-de-Marne, en trois pistes graphiques (A, A3, A4), pour choisir la direction à retenir.

Ouvrir `index.html` : la page d'entrée présente les trois pistes. Dans chaque piste, la barre grise du haut permet de revenir aux trois pistes ou de passer à la même page dans une autre piste.

Maquettes de travail de novembre 2026 : photos provisoires, formulaires factices. Les pages ne sont pas indexées par les moteurs de recherche.
